# آب‌وهوای قندیل

نسخهٔ ۲.۰.۰ برنامهٔ اندرویدی قندیل.

## پوسته‌های ظاهری

- **آسمان آبی:** رابط شیشه‌ای آبی بر پایهٔ طرح تازهٔ ارائه‌شده

- **قندیل پویا:** طراحی تازه با پس‌زمینهٔ آسمانی تیره و کارت‌های شیشه‌ای
- **آسمانی روشن:** طراحی روشن نسخهٔ قبل
- **شب قندیل:** پوستهٔ تیره و مینیمال
- **هماهنگ با دستگاه:** انتخاب روشن یا تیره بر اساس تنظیم گوشی

انتخاب پوسته از تنظیمات برنامه انجام می‌شود و در حافظهٔ دستگاه ذخیره می‌ماند؛ تغییر آن نیازی به دریافت دوبارهٔ اطلاعات هواشناسی ندارد.

## فناوری‌ها

- Kotlin برای میزبان اندروید، WebView و اعلان‌ها
- TypeScript برای هستهٔ منطق هواشناسی
- Python برای ادغام و کنترل کیفیت پروژه
- HTML/CSS/JavaScript برای رابط کاربری

## ساخت

```bash
npm install
npm run build:core
npm run test:core
python3 tools/validate_project.py
gradle assembleRelease
```

## انتشار

با هر push به شاخهٔ `main`، GitHub Actions فایل APK امضاشده را با کلید دائمی می‌سازد و در Release نسخهٔ جاری منتشر می‌کند. شناسهٔ بسته و کلید امضا برای نصب به‌روزرسانی حفظ می‌شوند.
