# آب‌وهوای پیرانشهر

پروژهٔ اپلیکیشن اندرویدی آب‌وهوای پیرانشهر.

## ساخت خودکار APK

1. فایل `PiranshahrWeather-GitHub.zip` را از بستهٔ آمادهٔ پروژه دانلود کنید.
2. آن را در ریشهٔ این مخزن GitHub بارگذاری کنید (Add file → Upload files) و تغییرات را روی شاخهٔ `main` ثبت کنید.
3. از بخش **Actions** اجرای **Build Piranshahr Weather APK** را باز کنید.
4. پس از موفقیت، APK در بخش Artifacts همان اجرا و در قسمت Releases منتشر می‌شود.

Workflow آرشیو پروژه را استخراج می‌کند و با JDK 17 و Gradle 8.6 نسخهٔ Debug را می‌سازد.

## ساختار پروژه

کد اصلی پس از استخراج در پوشهٔ `piranshahr-weather-android/` قرار می‌گیرد.
