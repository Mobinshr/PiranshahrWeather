# آب‌وهوای قندیل

برنامهٔ اندرویدی آب‌وهوای قندیل با جست‌وجوی شهرهای ایران، GPS، پیش‌بینی ساعتی و هفت‌روزه و هشدار بارش.

## امکانات نسخهٔ 3.2.0
- نام و آیکون اختصاصی گرافیتی قندیل.
- رابط سبک‌تر: حذف blurهای سنگین و فونت خارجی.
- ذخیرهٔ موقت پیش‌بینی و کاهش درخواست‌های تکراری شبکه.
- جست‌وجوی شهرهای ایران از سرویس مکان‌یابی و دریافت وضعیت با GPS.
- نمایش احتمال بارش در ساعت‌های آینده و روزهای هفته، به‌همراه مقدار بارش به میلی‌متر.
- هشدار بارش از طریق اعلان بومی اندروید؛ برای دریافت آن باید مجوز اعلان فعال باشد.

ساخت APK از طریق GitHub Actions انجام می‌شود.
