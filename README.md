# آب‌وهوای قندیل

نسخهٔ بازنویسی‌شدهٔ فنی برنامهٔ اندرویدی قندیل، با حفظ شناسهٔ بسته و امضای انتشار فعلی.

## فناوری‌ها و نقش هرکدام

- **Kotlin:** میزبان native اندروید، WebView، اعلان‌ها و ارتباط با قابلیت‌های گوشی.
- **TypeScript:** هستهٔ اصلی منطق هواشناسی؛ داده‌های شهرها، ساخت درخواست‌های Open-Meteo، دسته‌بندی شاخص کیفیت هوا، محاسبات بارش و بازهٔ پیش‌بینی. این هسته برای اجرا در WebView به JavaScript کامپایل می‌شود.
- **HTML و CSS:** ساختار و رابط کاربری برنامه.
- **Python:** ادغام خودکار هستهٔ TypeScript با پروژهٔ اندروید و اعتبارسنجی فایل‌ها در فرایند Build.
- **JavaScript:** خروجی اجرایی مرورگر از TypeScript و کدهای رابط فعلی.

Java به‌صورت موازی اضافه نشده است؛ در این پروژه Kotlin برای لایهٔ native کافی است. JSON نیز قالب تبادل داده است، نه زبان برنامه‌نویسی.

## توسعهٔ هستهٔ TypeScript

نیازمندی‌ها: Node.js 22 یا جدیدتر و Python 3.

```bash
npm install --no-audit --no-fund --no-package-lock
npm run build:core
npm run test:core
```

## ساخت APK

GitHub Actions پس از هر تغییر مرتبط، هستهٔ TypeScript را کامپایل و تست می‌کند، پروژهٔ Android را از آرشیو سورس استخراج می‌کند، ادغام و اعتبارسنجی Python را اجرا می‌کند و APK امضاشده را می‌سازد.

فایل‌های کلیدی:

- `src/core/weather-core.ts`: منطق مرکزی و تایپ‌های دادهٔ هواشناسی
- `tests/weather-core.test.cjs`: آزمون‌های هسته
- `tools/integrate_weather_core.py`: تزریق خروجی کامپایل‌شده در WebView و همگام‌سازی نام برنامه
- `tools/validate_project.py`: بررسی یکپارچگی پروژه پیش از Build

## سازگاری به‌روزرسانی

شناسهٔ بستهٔ اندروید `com.example.weather` و امضای انتشار قبلی حفظ می‌شوند تا نسخهٔ جدید به‌صورت به‌روزرسانی روی نصب فعلی قابل نصب باشد. نسخهٔ برنامه در این مرحله به `1.7.0` ارتقا داده شده است.
