# آب‌وهوای قندیل

نسخهٔ ۳.۰.۰ برنامهٔ اندرویدی آب‌وهوای پیرانشهر.

## امکانات نسخهٔ ۳.۰.۰

- رابط برنامه مستقیماً از فایل HTML ارائه‌شده ساخته می‌شود؛ طراحی قبلی برنامه جایگزین شده است.
- جست‌وجوی پویا و فارسی شهرها با محدودیت کشور ایران.
- دریافت آب‌وهوا بر اساس GPS و تلاش برای تشخیص نام شهر از مختصات.
- پیش‌بینی ساعتی و هفت‌روزه، شاخص UV، غروب و طلوع، باد، رطوبت و احتمال بارش.
