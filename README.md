# آب‌وهوای قندیل

نسخهٔ اندرویدی برنامهٔ آب‌وهوای قندیل با جست‌وجوی شهرهای ایران، موقعیت‌یابی GPS، پیش‌بینی ساعتی و هفت‌روزه و نمایش احتمال و مقدار بارش.

## امکانات نسخهٔ 3.1.0
- رابط سبک‌تر با حذف افکت‌های سنگین blur و فونت خارجی.
- ذخیرهٔ موقت پیش‌بینی برای نمایش سریع‌تر و کاهش درخواست‌های شبکه.
- جست‌وجوی شهرهای ایران از سرویس مکان‌یابی و دریافت وضعیت با GPS.
- نمایش احتمال بارش ساعتی و روزانه و مقدار بارش پیش‌بینی‌شده.
- آماده‌سازی اعلان بارش در رابط برنامه؛ اعلان سیستمی در پس‌زمینه به پشتیبانی لایهٔ بومی اندروید نیاز دارد.
- آیکون اختصاصی با حال‌وهوای گرافیتی.

ساخت APK از طریق GitHub Actions انجام می‌شود.
