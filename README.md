# آب‌وهوای قندیل

نسخهٔ بازطراحی‌شدهٔ برنامهٔ اندرویدی قندیل.

## طراحی نسخهٔ ۱.۸.۰

- رابط کاربری تازه با پس‌زمینهٔ روشن آسمانی، کارت هواشناسی شاخص و چیدمان خلوت‌تر
- نمایش دمای فعلی و وضعیت هوا در اولویت
- پیش‌بینی ساعتی و هفت‌روزه با خوانایی بهتر
- نمودار دما و احتمال بارش با فضای بصری ساده‌تر
- کارت‌های خلاصهٔ شاخص‌های هواشناسی و طلوع/غروب
- پشتیبانی از تم روشن و تیره بر اساس تنظیم سیستم
- واکنش‌گرایی برای نمایشگرهای کوچک

## فناوری‌ها

- Kotlin برای میزبان اندروید، WebView و اعلان‌ها
- TypeScript برای هستهٔ محاسبات و داده‌های هواشناسی
- Python برای ادغام و اعتبارسنجی فرایند ساخت
- HTML/CSS و JavaScript برای رابط کاربری و اجرا در WebView

## سازگاری

شناسهٔ بستهٔ اندروید و کلید امضای انتشار قبلی حفظ شده‌اند تا نسخهٔ جدید به‌صورت به‌روزرسانی نصب شود.
